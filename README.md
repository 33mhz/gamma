# Gamma

Forked from https://github.com/sunya9/Gamma.

A general-use Android app for pnut.io.

Pull requests welcome!

We have been using https://developer.android.com/studio to build. Hoping to provide apk, F-Droid, and Google Play Store access.

Google Firebase/Crashlytics is used for error tracking, but only included if you build with a `google-services.json` in the `/app` folder.
